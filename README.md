# Finance Ops — 30 / 60 / 90

A single-page operating plan for a **two-person finance team** at an AI-native consulting firm.

## Themes

1. **Protect cash** — 13-week forecast, order-to-cash, collections
2. **Lean controls** — revenue vs. cost ownership, lightweight approvals
3. **Automate to scale** — billing, expenses, recon, and anomaly checks without adding headcount

## Open locally

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Then visit `http://127.0.0.1:8000`.

## Contents

| Days | Focus |
| --- | --- |
| 1–30 | Stabilize: cash visibility, DSO/WIP, cost audit, close process |
| 31–60 | Build: automation, project margin (incl. AI spend), rev rec, dashboard |
| 61–90 | Optimize: pricing input, scenarios, concentration risk, scale readiness |
